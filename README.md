### Transaction Processing Flow
```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         TRANSACTION REQUEST                                │
│                    (Deposit or Withdraw DTO)                               │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
                    ┌─────────────────────────────────┐
                    │   Check: Is this a DEPOSIT or   │
                    │         WITHDRAW?               │
                    └─────────────────────────────────┘
                           │                  │
                    ┌──────▼──────┐    ┌──────▼──────┐
                    │   DEPOSIT   │    │  WITHDRAW   │
                    └──────┬──────┘    └──────┬──────┘
                           │                  │
                           ▼                  ▼
              ┌─────────────────┐  ┌─────────────────────────┐
              │ Check: Does     │  │ Acquire PESSIMISTIC     │
              │ referenceId     │  │ WRITE LOCK on Account   │
              │ exist?          │  │ (findByIdWithLocking)   │
              └─────────────────┘  └─────────────────────────┘
                    │        │                  │
             YES    │        │ NO        ┌──────▼──────┐
           ┌────────▼──┐     │          │ Check: Is   │
           │ Throw 409  │     │          │ Balance -   │
           │ Conflict   │     │          │ Amount < 0? │
           └────────────┘     │          └──────┬──────┘
                              │             YES  │   NO
                              │          ┌───────▼────┐
                              │          │ Rollback   │
                              │          │ & Throw    │
                              │          │ 400 Error  │
                              │          └────────────┘
                              │                  │
                              ▼                  ▼
                   ┌─────────────────────────────────────┐
                   │   UPDATE BALANCE                     │
                   │   (Deposit: balance + amount)        │
                   │   (Withdraw: balance - amount)       │
                   └─────────────────────────────────────┘
                              │
                              ▼
                   ┌─────────────────────────────────────┐
                   │   SAVE TRANSACTION RECORD           │
                   │   (AuditLog via AOP captures        │
                   │    old/new balance)                 │
                   └─────────────────────────────────────┘
                              │
                              ▼
                   ┌─────────────────────────────────────┐
                   │   RETURN TransactionResponseDTO     │
                   └─────────────────────────────────────┘
